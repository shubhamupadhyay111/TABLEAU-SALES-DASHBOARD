# TABLEAU-SALES-DASHBOARD
# 📊 Sales Dashboard Overview - Tableau

This repository contains a snapshot and description of an interactive **Sales Dashboard** built using **Tableau Desktop Public Edition**. The dashboard provides actionable insights into key sales performance metrics across different dimensions such as geography, segment, and manager.

## 🚀 Features

- **Total Sales, Profit, and Quantity** KPIs with YoY comparisons
- **State-wise Sales and Profit Distribution** map
- **Monthly Sales Trends** for Consumer, Corporate, and Home Office segments
- **Sales Above/Below Average** visualizations by state
- **Manager & Region-level Performance Breakdown**
- Interactive filters for:
  - Ship Mode
  - Country/Region
  - Region
  - Category

## 🛠️ Built With

- [Tableau Desktop Public Edition](https://public.tableau.com/en-us/s/download)
- Sample sales dataset (anonymized and formatted)

## 📈 Purpose

This dashboard is designed to:
- Provide a comprehensive overview of sales performance.
- Help decision-makers identify growth opportunities.
- Allow filtering and dynamic exploration of sales metrics.

## 📎 How to Use

1. Open the `.twbx` file (if available) using Tableau Desktop Public Edition.
2. Use the dropdown filters to adjust view by Ship Mode, Region, etc.
3. Hover over charts and maps to see detailed tooltips and metrics.
4. Analyze performance by segment and region to identify insights.

## 🖼️ Screenshot
